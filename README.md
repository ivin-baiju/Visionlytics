# Visionlytics

**Visionlytics** is a full-stack computer vision telemetry and model training platform for images, videos, live webcams, and RTSP streams. Every frame is analyzed for people counts, persistent multi-object track IDs, trajectories, polygon zone occupancy, and foreground-masked **CIE 1976 $L^*a^*b^*$ + CIEDE2000 ($\Delta E_{00}$)** object and garment colours.

## Architecture

```mermaid
flowchart LR
  subgraph Client
    WEB["apps/web (React 19 + Vite 8 + Tailwind v4 + WebGL2 Grid Shader)"]

  end
  WEB -- "REST / OpenAPI 3.1" --> API["apps/api (Fastify 5 + Zod + Drizzle)"]
  API --> PG[("PostgreSQL 16 + TimescaleDB Hypertable")]
  API --> REDIS[("Redis 7 + BullMQ Queues")]
  API --> S3[("SeaweedFS / R2 S3-Compatible Storage")]
  API -- "HTTP / ONNX Runtime" --> ML["apps/ml (FastAPI + Python 3.12 + ONNX Runtime 1.31)"]
```

### Monorepo Layout
- `apps/web` — React 19 + TypeScript + Vite 8 application (Overview, Analyze Workspace & 60fps Canvas Overlay, Interactive Polygon Zone & Line Editor, Alert Rules, Event Search & CSV/JSON Export, Training Studio, Model Registry with Promotion Gate, Organization & SHA-256 API Key Governance).
- `apps/api` — Fastify 5 + Drizzle ORM + TimescaleDB (`frame_events` hypertable) + BullMQ + S3 presigned uploads + OpenAPI 3.1 (`/docs`).
- `apps/ml` — Python 3.12 + FastAPI + ONNX Runtime (`1.31.1`) serving Apache-2.0 `RT-DETRv2-R18vd-INT8` and `YOLOS-Tiny-INT8`, `ByteTrackerWithReID`, foreground CIELAB/CIEDE2000 colour pipeline, and continuous evaluation harness (`visionlytics_ml/eval_harness.py`).
- `packages/ui` — "Precision optics" design system tokens (`tokens.css`), spring motion tokens (`motion.ts`), accessible Radix-based components, and Storybook 10 stories.
- `packages/shared-types` — Shared Zod schemas and the TypeScript SDK (`VisionlyticsClient`).
- `packages/video` — Remotion video specifications and deterministic timeline keyframe builders.

## Quickstart (< 2 Minutes)

### One-Command Full Stack (Docker Compose)
```bash
pnpm up
# Or directly:
docker compose up -d --build --wait
```

Once healthy:
- **Web Workspace**: http://localhost:5173
- **API & OpenAPI 3.1 Swagger UI**: http://localhost:4000/docs
- **API Readiness Probe**: http://localhost:4000/readyz
- **ML Runtime & Evaluation Metrics**: http://localhost:8000/eval/metrics
- **Storybook Design System**: `pnpm storybook` (http://localhost:6006)
